# 格式转换模板合集

> 本文件包含 4 个格式转换模板：文本转 JSON / 文本转表格 / 文本转大纲 / 表格转文本。每个模板含完整 Prompt 与输入输出示例，覆盖非结构化与结构化数据互转的核心场景。

---

## 模板 1：文本转 JSON - 非结构化客服记录转结构化数据

### 模板说明
- 用途：将非结构化的客服记录文本转为符合 Schema 的结构化 JSON
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{unstructured_text}}`、`{{json_schema}}`

### 完整模板

```text
你是数据结构化引擎。请将以下非结构化文本转为符合 Schema 的 JSON。

【非结构化文本】
{{unstructured_text}}

【目标 JSON Schema】
{{json_schema}}

【转换规则】
1. 严格遵循 Schema 字段名、类型、必填性
2. 文本中未提及的字段：
   - 必填字段：填 null 并在 errors 中说明
   - 非必填字段：直接填 null
3. 数值字段去掉单位（如"299 元" → 299）
4. 日期字段统一为 ISO 8601（YYYY-MM-DD）
5. 枚举字段必须取 Schema 中定义的值
6. 数组字段若文本中只有 1 个值，仍输出数组
7. 不得编造文本中没有的字段值

【输出格式】
{
  "data": { ...符合 Schema 的 JSON },
  "errors": [
    {"field": "缺失或非法的字段", "reason": "原因"}
  ],
  "confidence": 0.0-1.0
}

约束：只输出 JSON，不输出解释。
```

### 使用示例

#### 输入
```text
你是数据结构化引擎。请将以下非结构化文本转为符合 Schema 的 JSON。

【非结构化文本】
客户张先生于 11 月 5 日来电，反映 10 月 28 日下单的订单 20251028-009（索尼 WH-1000XM5 耳机，2399 元）至今未收到货。客户情绪较激动，要求要么 3 天内送达，要么全额退款。客服已安抚并加急处理，承诺 11 月 6 日前回复处理结果。

【目标 JSON Schema】
{
  "ticket_id": "string (auto)",
  "customer_name": "string",
  "contact_date": "string (ISO 8601)",
  "order_id": "string",
  "product_name": "string",
  "amount": "number",
  "issue_type": "enum: logistics_delay | quality_issue | refund_dispute | other",
  "customer_emotion": "enum: calm | upset | angry",
  "customer_demand": "string",
  "action_taken": "string",
  "promise_date": "string (ISO 8601)",
  "status": "enum: pending | processing | resolved | escalated"
}

（转换规则同上）
```

#### 预期输出
```json
{
  "data": {
    "ticket_id": null,
    "customer_name": "张先生",
    "contact_date": "2025-11-05",
    "order_id": "20251028-009",
    "product_name": "索尼 WH-1000XM5 耳机",
    "amount": 2399,
    "issue_type": "logistics_delay",
    "customer_emotion": "angry",
    "customer_demand": "3 天内送达或全额退款",
    "action_taken": "安抚并加急处理",
    "promise_date": "2025-11-06",
    "status": "processing"
  },
  "errors": [
    {"field": "ticket_id", "reason": "文本中未提及工单编号"}
  ],
  "confidence": 0.92
}
```

### 调优建议
- 温度：0.0（结构化需稳定）
- Schema 越清晰，输出越准确，建议用 JSON Schema 标准格式
- 转换后建议用 jsonschema 库二次校验
- 大批量转换可分批处理，每批 10-20 条

## 模板 2：文本转表格 - 产品信息转 Markdown 表格

### 模板说明
- 用途：把描述性的产品信息文本转为 Markdown 表格
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{text}}`、`{{table_columns}}`

### 完整模板

```text
你是数据整理专家。请将以下文本转为 Markdown 表格。

【文本】
{{text}}

【表格列定义】
{{table_columns}}

【转换要求】
1. 严格按列定义输出表格
2. 表头使用列定义中的"显示名"
3. 单元格内容简洁，避免长句
4. 数值统一单位（如金额统一为"元"）
5. 缺失字段填 "—"
6. 表格下方附"数据说明"小节，说明：
   - 数据来源段落
   - 任何需要人工核对的疑点

【输出格式】
{
  "table": "Markdown 表格（含表头）",
  "row_count": 行数,
  "notes": ["说明1", "..."],
  "doubtful_points": ["疑点1", "..."]
}

约束：
1. 不得编造文本中没有的数据
2. 只输出 JSON
```

### 使用示例

#### 输入
```text
你是数据整理专家。请将以下文本转为 Markdown 表格。

【文本】
本次上新 4 款耳机。
第一款是索尼 WH-1000XM5，主动降噪，30 小时续航，售价 2399 元，库存 200。
第二款是 Bose QC45，主动降噪，24 小时续航，售价 1999 元，库存 150。
第三款是苹果 AirPods Pro 2，主动降噪，6 小时续航（单次），售价 1899 元，库存 300。
第四款是森海塞尔 Momentum 4，主动降噪，60 小时续航，售价 2199 元，库存暂未到货。

【表格列定义】
- product_name：产品名称
- brand：品牌
- noise_cancelling：是否降噪
- battery_hours：续航（小时）
- price_cny：售价（元）
- stock：库存

（转换要求同上）
```

#### 预期输出
```json
{
  "table": "| 产品名称 | 品牌 | 是否降噪 | 续航（小时） | 售价（元） | 库存 |\n|---------|------|---------|------------|----------|------|\n| 索尼 WH-1000XM5 | 索尼 | 是 | 30 | 2399 | 200 |\n| Bose QC45 | Bose | 是 | 24 | 1999 | 150 |\n| AirPods Pro 2 | 苹果 | 是 | 6 | 1899 | 300 |\n| Momentum 4 | 森海塞尔 | 是 | 60 | 2199 | — |",
  "row_count": 4,
  "notes": [
    "续航字段：AirPods Pro 2 文本注明为'单次'续航，其他为总续航",
    "金额单位统一为元"
  ],
  "doubtful_points": [
    "Momentum 4 库存未到货，已填'—'，建议补到货时间"
  ]
}
```

### 调优建议
- 温度：0.0
- 列定义越明确越好，避免歧义
- 若文本中数据维度不一致（如部分产品缺字段），doubtful_points 字段可帮助人工核对
- 表格行数较多时，建议分批转换

## 模板 3：文本转大纲 - 长文转层级大纲

### 模板说明
- 用途：把长文转为层级化大纲，便于快速浏览与导航
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{long_text}}`、`{{max_depth}}`、`{{style}}`

### 完整模板

```text
你是文档结构化专家。请将以下长文转为层级大纲。

【长文】
{{long_text}}

【大纲要求】
1. 最大层级深度：{{max_depth}} 级（如 1.1.1）
2. 风格：{{style}}（标题式 / 摘要式）
3. 每个节点：
   - 标题式：仅标题，简短（≤20 字）
   - 摘要式：标题 + 一句话摘要（≤30 字）
4. 编号格式：1 / 1.1 / 1.1.1
5. 同级节点逻辑平行，互不重叠
6. 不得编造原文没有的章节

【输出格式】
{
  "outline": [
    {
      "number": "1",
      "title": "章节标题",
      "summary": "摘要式时填写，标题式为 null",
      "children": [
        {"number": "1.1", "title": "...", "summary": "...", "children": []}
      ]
    }
  ],
  "total_sections": 总章节数,
  "max_depth_reached": 实际最大层级
}

约束：只输出 JSON。
```

### 使用示例

#### 输入
```text
你是文档结构化专家。请将以下长文转为层级大纲。

【长文】
（节选自退换货政策）
第一章 适用范围
第 1 条 本政策适用于本平台所售实物商品，不适用定制类、生鲜、数字内容、已拆封卫生用品、跨境购。
第 2 条 企业用户适用单独协议。
第 3 条 跨境购不适用 7 天无理由退货。

第二章 退换货条件
第 4 条 7 天无理由：自签收起 7 天内可退货，商品需完好、配件齐全。
第 5 条 15 天质量问题：自签收起 15 天内可退换，运费平台承担。
第 6 条 不适用情形：定制类已开始生产、生鲜已签收、数字内容已激活。

第三章 流程
第 7 条 申请：用户在订单页提交退换货申请。
第 8 条 审核：客服 1 个工作日内审核。
第 9 条 寄回：审核通过后用户 7 天内寄回。
第 10 条 验收：仓库 3 个工作日内验收。
第 11 条 退款：验收通过后 3 个工作日内退款。

【大纲要求】
1. 最大层级深度：3 级
2. 风格：摘要式
3. 编号格式：1 / 1.1 / 1.1.1

（输出格式同上）
```

#### 预期输出
```json
{
  "outline": [

      "number": "1",
```

- 输出的 outline 结构可直接渲染为前端目录树

## 模板 4：表格转文本 - 数据表转叙述性描述

### 模板说明
- 用途：把数据表格转为连贯的叙述性文本，便于阅读与汇报
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{table_data}}`、`{{narrative_focus}}`、`{{style}}`

### 完整模板

```text
你是数据叙述化专家。请将以下表格数据转为叙述性文本。

【表格数据】
{{table_data}}

【叙述重点】
{{narrative_focus}}

【风格要求】
{{style}}

【转换要求】
1. 不简单罗列数据，而是按重点组织叙述
2. 突出关键发现：最高 / 最低 / 异常 / 趋势
3. 必须包含：
   - 总体概述（1-2 句）
   - 关键数据点（保留具体数值）
   - 对比与差异（如有）
   - 简短结论（1-2 句）
4. 字数：200-500 字
5. 不得编造表格中没有的数据

【输出格式】
{
  "narrative": "叙述性文本",
  "key_findings": ["发现1", "发现2", "..."],
  "conclusion": "结论（≤50 字）"
}

约束：只输出 JSON。
```

### 使用示例

#### 输入
```text
你是数据叙述化专家。请将以下表格数据转为叙述性文本。

【表格数据】
| 产品名称 | 销量 | 销售额（元） | 环比 |
|---------|------|------------|------|
| 索尼 WH-1000XM5 | 1,200 | 2,878,800 | +15% |
| Bose QC45 | 800 | 1,599,200 | -5% |
| AirPods Pro 2 | 1,500 | 2,848,500 | +22% |
| Momentum 4 | 300 | 659,700 | -10% |

【叙述重点】
Q4 降噪耳机品类销售表现，重点关注增长与下滑原因

【风格要求】
客观、数据导向，适合运营周报

（转换要求同上）
```

#### 预期输出
```json
{
  "narrative": "本季度降噪耳机品类共实现销量 3,800 台，销售额约 798.6 万元。从单品表现看，AirPods Pro 2 以 1,500 台销量领跑，环比增长 22%，是本季度增长的主要驱动力；索尼 WH-1000XM5 紧随其后，销量 1,200 台，环比增长 15%，且凭借较高的客单价（2,399 元）成为销售额第一的单品。相比之下，Bose QC45 与森海塞尔 Momentum 4 均出现下滑，分别环比 -5% 与 -10%，Momentum 4 销量仅 300 台，是本季度表现最弱的单品。整体看，苹果与索尼两大品牌贡献了品类 72% 的销售额，集中度较高。",
  "key_findings": [
    "AirPods Pro 2 销量第一（1,500 台），环比 +22%，是增长主因",
    "索尼 WH-1000XM5 销售额第一（287.9 万元），客单价较高",
    "Bose QC45 与 Momentum 4 均下滑，Momentum 4 销量仅 300 台",
    "苹果 + 索尼合计占品类销售额 72%，集中度高"
  ],
  "conclusion": "品类增长由苹果与索尼双轮驱动，Bose 与森海塞尔需针对性复盘下滑原因。"
}
```

### 调优建议
- 温度：0.3（叙述需基于数据，少量发挥）
- 若表格数据量大，可先用统计 Prompt 算出关键指标再叙述
- 叙述化文本适合放入周报、邮件、PPT 文案
- key_findings 字段便于人工快速核对结论
