# 内容创作模板合集

> 本文件包含 5 个内容创作模板：营销文案 / 邮件写作 / 报告生成 / FAQ 生成 / 社交媒体文案。每个模板含完整 Prompt 与生成示例。

## 模板 1：营销文案 - 产品标题 + 广告语 + 产品描述

### 模板说明
- 用途：为电商产品生成营销文案三件套（标题 / 广告语 / 描述）
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{product_info}}`、`{{target_audience}}`、`{{brand_tone}}`

### 完整模板

```text
你是资深电商文案策划。请根据产品信息生成营销文案三件套。

【产品信息】
{{product_info}}

【目标受众】
{{target_audience}}

【品牌调性】
{{brand_tone}}

【输出要求】
1. 产品标题：
   - 5 个候选，每个 ≤30 字
   - 突出核心卖点
   - 含 1-2 个 SEO 关键词

2. 广告语：
   - 5 个候选，每个 ≤15 字
   - 朗朗上口，便于记忆

3. 产品描述：
   - 200-300 字
   - 结构：开篇吸引 → 卖点展开（3 个）→ 使用场景 → 行动号召
   - 含具体使用场景，避免空泛形容

【输出格式】
{
  "titles": ["标题1", "标题2", "..."],
  "slogans": ["广告语1", "广告语2", "..."],
  "description": "产品描述正文",
  "selling_points_used": ["实际用到的卖点"],
  "cta": "行动号召（≤15 字）"
}

约束：
1. 不得使用绝对化用语（"最""第一""100%"）
2. 不得编造产品信息中没有的功能
3. 只输出 JSON
```

### 使用示例

#### 输入
```text
你是资深电商文案策划。请根据产品信息生成营销文案三件套。

【产品信息】
产品：索尼 WH-1000XM5 降噪耳机
核心卖点：
- 行业领先的主动降噪
- 30 小时续航
- 佩戴舒适，重量仅 250g
- 支持 LDAC 高解析度音频
价格：2399 元

【目标受众】
25-40 岁都市白领，通勤族，追求音质与降噪

【品牌调性】
专业、品质、科技感

（输出要求同上）
```

```json
{
  "titles": [
    "索尼 WH-1000XM5 降噪耳机 30 小时续航通通勤神器",
    "通勤安静一点 索尼 XM5 降噪耳机 250g 轻量佩戴",
```

## 模板 2：邮件写作 - 客户关怀邮件模板

### 模板说明
- 用途：根据客户标签与场景生成客户关怀邮件
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{customer_info}}`、`{{care_scenario}}`、`{{brand_tone}}`

### 完整模板

```text
你是客户关系管理专家。请根据客户信息与场景生成客户关怀邮件。

【客户信息】
{{customer_info}}

【关怀场景】
{{care_scenario}}

【品牌调性】
{{brand_tone}}

【邮件要求】
1. 主题行：≤30 字，引发打开欲望，避免营销感过强
2. 称呼：个性化（用客户姓名）
3. 正文：
   - 200-400 字
   - 结构：关怀开头 → 价值提供 → 软性推荐 → 行动号召
   - 体现"懂客户"，避免模板感
4. 落款：品牌名 + 客服团队
5. 邮件语气：亲切但不逾矩，避免过度承诺

【输出格式】
{
  "subject": "邮件主题",
  "body": "邮件正文（含称呼与落款）",
  "personalization_points": ["个性化点1", "..."],
  "cta": "行动号召",
  "send_timing_suggestion": "建议发送时间"
}

约束：
1. 不得编造客户未提供的购买历史
2. 不得使用"立即下单"等强营销话术
3. 只输出 JSON
```

### 使用示例

#### 输入
```text
你是客户关系管理专家。请根据客户信息与场景生成客户关怀邮件。

【客户信息】
姓名：张先生
会员等级：gold
最近一次购买：3 个月前买了索尼 WH-1000XM5 耳机
购买频次：年累计 8 单
偏好品类：数码、耳机配件

【关怀场景】
购买满 3 个月，主动关怀使用体验 + 推荐耳机配件（耳机架、收纳盒）

【品牌调性】
专业、贴心、不打扰

（邮件要求同上）
```

#### 预期输出
```json
{
  "subject": "张先生，XM5 用得怎么样？我们准备了点小礼物",
  "body": "张先生您好：\n\n3 个月前您带走了索尼 WH-1000XM5，不知道这 3 个月的通勤是否安静了一些？\n\n作为我们的 gold 会员，您对音质的追求我们一直记着。这段时间，不少和您一样选择 XM5 的朋友，会再配一个耳机架和硬壳收纳盒——既能在办公桌上稳妥安放，也能出差时保护耳机不被压坏。\n\n如果您感兴趣，这两款配件现在对 gold 会员有 8.5 折，链接在下方。\n\n当然，如果您使用中遇到任何问题，欢迎随时回复本邮件，SmartCS 客服团队会第一时间为您处理。\n\n祝您听歌愉快。\n\nSmartCS 客户关怀团队",
  "personalization_points": [
    "称呼用张先生",

    "结合 gold 会员身份提供专属折扣",
    "根据 gold 会员偏好品类推荐配件"

  "cta": "查看 gold 会员专属配件折扣",
```

- 温度：0.6
- 邮件主题决定打开率，建议生成 5 个候选主题择优
- 若用于营销自动化，可追加"输出 HTML 版本含按钮"

## 模板 3：报告生成 - 客服周报自动生成

### 模板说明
- 用途：根据一周客服数据自动生成结构化周报
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{week_data}}`、`{{report_audience}}`

### 完整模板

```text
你是客服运营数据分析专家。请根据以下数据生成本周客服周报。

【本周数据】
{{week_data}}

【报告受众】
{{report_audience}}

【报告结构】
1. 本周概况：1 段 + 3 个核心指标
2. 关键数据：用 Markdown 表格呈现
3. 典型案例：2-3 个代表性案例
4. 问题与改进：识别问题 + 给出可执行建议

【写作要求】
1. 数据准确，不得编造或夸大
2. 结论基于数据，避免主观臆断
3. 改进建议必须可执行（明确负责人 / 时间 / 衡量指标）
4. 字数：800-1500 字
5. 风格：客观、专业、面向决策

【输出格式】
{
  "title": "周报标题",
  "overview": "本周概况（含 3 个核心指标）",
  "key_metrics_table": "Markdown 表格",
  "typical_cases": ["案例1", "案例2", "..."],
  "issues": [
    {"issue": "问题描述", "evidence": "数据依据", "suggestion": "改进建议", "owner": "建议负责人", "kpi": "衡量指标"}
  ],
  "next_week_focus": "下周重点（≤80 字）"
}

约束：只输出 JSON。
```

### 使用示例

#### 输入
```text
你是客服运营数据分析专家。请根据以下数据生成本周客服周报。

【本周数据】
- 咨询总量：3,420 单（环比 +5.2%）
- 订单查询：1,440（42%）
- 退换货：790（23%）
- 物流咨询：620（18%）
- 投诉：156（4.6%）
- 其他：414
- 平均首响：1 分 23 秒（环比 -12 秒）
- 一次性解决率：78%（环比 +3 个百分点）
- 客户满意度：4.6/5.0（环比 -0.1）
- 投诉明细：物流延迟 68 单、包装破损 42 单、客服态度 22 单、产品质量 24 单
- 典型案例：
  案例 A：用户订单 20251028-009 物流延迟 5 天，客服加急处理后次日送达，用户最终满意
  案例 B：用户收货包装破损，耳机外观受损，客服安排换货并补偿 50 元券

【报告受众】
客服部门负责人 + 运营总监

（报告结构、写作要求同上）
```

#### 预期输出

## 模板 4：FAQ 生成 - 从知识库生成 FAQ 问答对

### 模板说明
- 用途：从知识库文档自动生成 FAQ 问答对，用于客服系统填充
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{knowledge_base}}`、`{{faq_count}}`、`{{audience}}`

### 完整模板

```text
你是知识库整理专家。请根据以下知识库文档生成 FAQ 问答对。

【知识库文档】
{{knowledge_base}}

【生成要求】
1. 生成 {{faq_count}} 条 FAQ
2. 面向读者：{{audience}}
3. 问题设计原则：
   - 站在用户视角提问（用"我""我的"）
   - 问题简短直接（≤25 字）
   - 覆盖知识库中的高频场景
4. 答案设计原则：
   - 直接回答问题（不绕弯）
   - 含具体数字 / 步骤 / 条件
   - 50-150 字
   - 若知识库无明确答案，标注"暂无明确说明"
5. 必须覆盖：适用范围、退换货条件、时效、运费、特殊情形

【输出格式】
{
  "faqs": [
    {
      "id": "FAQ-001",
      "category": "退换货条件 | 时效 | 运费 | 适用范围 | 特殊情形",
      "question": "问题",
      "answer": "答案",
      "source_reference": "知识库中依据的条款编号或段落"
    }
  ],
  "coverage_check": {
    "covered_topics": ["已覆盖主题"],
    "missing_topics": ["知识库中存在但未生成 FAQ 的主题"]
  }
}

约束：
1. 不得编造知识库中没有的信息
2. 只输出 JSON
```

```text
你是知识库整理专家。请根据以下知识库文档生成 FAQ 问答对。

【知识库文档】
第 1 条 本政策适用于本平台所售实物商品，不适用定制类、生鲜、数字内容、已拆封卫生用品、跨境购。
```

## 模板 5：社交媒体文案 - 微博 + 小红书风格

### 模板说明
- 用途：为同一产品生成微博与小红书两种风格的社媒文案
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{product_info}}`、`{{campaign_theme}}`

### 完整模板

```text
你是社媒运营专家。请根据产品信息生成微博与小红书两版文案。

【产品信息】
{{product_info}}

【活动主题】
{{campaign_theme}}

【平台风格要求】
微博版：
- 长度：≤140 字
- 风格：直接、有梗、易转发
- 必含：3-5 个 # 话题
- 适合：热点结合、信息速递

小红书版：
- 长度：300-500 字
- 风格：第一人称分享、有画面感、emoji 适度
- 结构：吸引标题 → 个人体验 → 卖点展开 → 互动号召
- 必含：emoji + 分段 + 标签

【输出格式】
{
  "weibo": {
    "content": "微博正文",
    "topics": ["#话题1#", "#话题2#"],
    "image_suggestion": "配图建议"
  },
  "xiaohongshu": {
    "title": "小红书标题（≤20 字，吸引点击）",
    "content": "小红书正文",
    "tags": ["标签1", "标签2"],
    "image_suggestion": "配图建议（首图 + 内页）"
  }
}

约束：
1. 不得使用绝对化用语
2. 不得编造产品没有的功能
3. 只输出 JSON
```

```text
你是社媒运营专家。请根据产品信息生成微博与小红书两版文案。

（平台风格要求同上）
```

### 调优建议
- 温度：0.8（社媒文案需高创造性）
- 不同平台用户画像差异大，建议分别生成不要一稿多投
- 小红书标题决定点击率，建议生成 5 个候选标题择优
- 微博话题建议参考当日热搜，提升曝光
