# 温度调参指南

> 本文件用同一 Prompt 在 Temperature = 0 / 0.3 / 0.7 / 1.0 下的输出对比，演示温度对 LLM 输出的影响，并给出 SmartCS 各场景的温度选择决策表。

---

## 一、温度原理速览

温度（Temperature）控制模型采样下一个 Token 时的随机性：

- **Temperature = 0**：贪婪解码，永远选概率最高的 token，输出几乎确定
- **Temperature 升高**：低概率 token 被选中的概率增加，输出更多样
- **Temperature = 1**：按原始概率分布采样
- **Temperature > 1**：分布被"拉平"，长尾 token 更易被选中（不推荐）

```
原始概率：  [退款 0.7, 换货 0.2, 维修 0.08, 咨询 0.02]
T=0  选：   退款（永远）
T=0.3 选：  退款（大概率），偶尔换货
T=0.7 选：  退款/换货都常见，偶尔维修
T=1.0 选：  按原分布，咨询也可能出现
```

## 二、同一 Prompt 不同温度输出对比

### 模板说明
- 用途：演示温度对意图识别与客服回复的影响
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{user_message}}`

### 测试 Prompt
```
你是 SmartCS 客服。用户说："我买的耳机好像有点问题，你们这能用多久啊？"
请生成一段回复，包括：1) 共情；2) 解答；3) 引导。不超过 80 字。
```

---

### Temperature = 0（确定性）

#### 预期输出（多次运行结果几乎相同）
```
您好，很抱歉耳机出现问题。我们的蓝牙耳机正常使用寿命约 2-3 年，若短期内出现故障可申请售后。请问具体是什么问题？我帮您排查或安排退换。
```

**特征**：
- 多次运行结果几乎一致
- 措辞标准、稳妥
- 适合需要稳定输出的场景

---

### Temperature = 0.3（低随机性）

#### 预期输出（运行 3 次的可能结果）
```
运行1：您好，抱歉耳机有问题。蓝牙耳机寿命约 2-3 年，短期故障可申请售后。请问具体故障现象？
运行2：很抱歉给您带来困扰。耳机正常使用 2-3 年，若出现问题可走售后。请问是什么问题？
运行3：您好，很抱歉。我们的耳机寿命约 2-3 年，早期故障可退换。请问具体什么情况？
```

**特征**：
- 核心信息一致，措辞略有变化
- 既有稳定性又有轻微差异
- 适合事实问答、摘要

---

### Temperature = 0.7（平衡）

#### 预期输出（运行 3 次的可能结果）
```
运行1：听到耳机有问题真抱歉～正常使用 2-3 年没问题，要是刚买不久就出状况，我可以帮您看看是退还是换。方便说说具体怎么个"有问题"法吗？
运行2：给您添麻烦了！这款耳机日常用个两三年没问题，但要是近期才出问题，咱可以走售后。您具体遇到的是杂音、连不上还是别的？
运行3：抱歉让您操心了。蓝牙耳机一般能用 2-3 年，短期内出问题建议尽快售后。方便描述下具体现象吗？我好帮您判断怎么处理最划算。
```

**特征**：
- 语气更自然、有温度
- 每次措辞差异明显，但都符合规范
- 适合客服对话、推荐

---

### Temperature = 1.0（高随机性）

#### 预期输出（运行 3 次的可能结果）
```
运行1：哎呀耳机闹脾气了？别急～这耳机好好伺候能用两三年，不过既然闹情绪了，咱就给它"办退学"或者"转学"也行。说说它怎么闹的？
运行2：太扫兴了！耳机本来能陪你两三年，既然它罢工了，退款换新随你挑。来，跟我讲讲它哪儿不对劲？
运行3：耳机也社恐？哈哈别担心，正常能用 2-3 年，早期出问题咱走售后。它是杂音、断连还是压根不开机呀？
```

**特征**：
- 风格差异巨大，可能出现比喻、网络用语
- 偶尔可能偏离专业客服定位
- 适合创意文案、头脑风暴，不适合严谨客服

## 三、温度选择决策表

| 场景 | 推荐 Temperature | 理由 | SmartCS 应用 |
|------|-----------------|------|-------------|
| 意图识别 | 0 | 需确定性分类 | intent classification |
| 信息抽取 | 0 | 字段必须准确 | 订单信息抽取 |
| 代码生成 | 0-0.2 | 代码需精确 | 客服脚本生成 |
| 事实问答 / FAQ | 0.2-0.3 | 准确为主，略微灵活 | FAQ 回答 |
| 摘要 / 翻译 | 0.3 | 忠实原文 | 工单摘要 |
| 客服对话 | 0.5-0.7 | 需人情味与多样性 | 多轮对话回复 |
| 商品推荐 | 0.4-0.6 | 稳定但略灵活 | 导购推荐 |
| 内容创作 | 0.7-0.9 | 需创意 | 商品描述生成 |
| 头脑风暴 | 0.9-1.0 | 越发散越好 | 活动 slogan 构思 |

## 四、三大场景温度实战

### 场景 1：意图识别（Temperature = 0）

### 模板说明
- 用途：用户消息意图分类，需稳定可复现
- 适用模型：通用
- 变量：`{{user_message}}`

### 完整模板
```
你是 SmartCS 意图识别模块。对用户消息分类，类别仅限：faq / order_query / refund / complaint / ticket。
用户消息：{{user_message}}
只输出类别名，不要解释。
```

### 调用参数
```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[...],
    temperature=0,      # ← 确定性输出
    top_p=1.0
)
```

### 预期输出（每次运行完全相同）
```
refund
```

### 调优建议
- 分类任务必须 T=0，否则同一输入每次分类可能不同，无法做自动化
- 配合 `response_format` 强制 JSON 输出更稳定

---

### 场景 2：客服对话（Temperature = 0.7）

### 模板说明
- 用途：生成有温度的客服回复
- 适用模型：通用
- 变量：`{{user_message}}`

### 完整模板
```
你是 SmartCS 客服，语气专业、温和、有同理心。请回复用户，包含共情与引导，不超过 100 字。
用户消息：{{user_message}}
```

### 调用参数
```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[...],
    temperature=0.7,    # ← 平衡
    top_p=1.0
)
```

### 预期输出
```
很抱歉耳机给您带来困扰，我非常理解您的心情。已为您记录问题，可申请退换货。请问您希望退款还是换新？我马上为您处理。
```

### 调优建议
- 客服对话 T=0.7 较合适：既不死板也不过度发挥
- 若希望回复更稳重，可降到 0.5；若希望更活泼，可升到 0.8
- 注意：T 过高可能输出不符合客服定位的用语，需配合 System 护栏

---

### 场景 3：创意文案（Temperature = 1.0）

### 模板说明
- 用途：为促销活动生成创意 slogan
- 适用模型：通用
- 变量：`{{product}}`、`{{promotion}}`

### 完整模板
```
你是 SmartCS 营销文案师。请为以下活动生成 5 条创意 slogan，要求新颖、有记忆点、不超过 15 字。
产品：{{product}}
活动：{{promotion}}
```

### 调用参数
```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[...],
    temperature=1.0,    # ← 高随机性
    top_p=0.95          # ← 略微过滤极端长尾
)
```

### 预期输出
```
1. 耳机一声，烦恼无踪
2. 戴上它，世界归你
3. 杂音退散，好声音上线
4. 一耳入魂，半价到手
5. 听见心动， smarter 选择
```

### 调优建议
- 创意文案 T=1.0 激发多样性，但需人工筛选
- 配合 `top_p=0.95` 过滤过于离谱的 token
- 可多次生成取优，或让 LLM 自己评估哪条最好

## 五、Temperature 与 Top-p 组合建议

| 组合 | 效果 | 适用 |
|------|------|------|
| T=0, top_p=1.0 | 完全确定 | 分类、抽取 |
| T=0.3, top_p=1.0 | 低随机 | FAQ、摘要 |
| T=0.7, top_p=1.0 | 平衡（推荐默认） | 对话、推荐 |
| T=1.0, top_p=0.9 | 创意但过滤长尾 | 文案、头脑风暴 |
| T=1.0, top_p=0.1 | 接近确定（用 top_p 控制） | 不常用 |

> 调参原则：**二选一调整**。要么调 Temperature（top_p=1.0），要么调 top_p（T=1.0），不要同时大幅改动两者，否则效果难以预测。

## 六、调参实验方法

### A/B 测试代码示例
```python
import openai

client = openai.OpenAI(api_key="your-key")

prompt = "你是 SmartCS 客服。回复：我买的耳机有杂音。不超过 50 字。"

for temp in [0, 0.3, 0.7, 1.0]:
    print(f"\n=== Temperature = {temp} ===")
    for i in range(3):
        resp = client.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": prompt}],
            temperature=temp,
            max_tokens=100
        )
        print(f"  运行{i+1}: {resp.choices[0].message.content}")
```

### 评估维度
| 维度 | 说明 | 适合高 T |
|------|------|---------|
| 准确性 | 是否符合事实 | 低 T |
| 稳定性 | 多次运行一致性 | 低 T |
| 多样性 | 表达丰富度 | 高 T |
| 创意性 | 新颖程度 | 高 T |
| 合规性 | 是否符合规范 | 低 T |

## 总结

| 温度 | 一句话 | SmartCS 模块 |
|------|--------|-------------|
| 0 | 要稳 | 意图识别、抽取、分类 |
| 0.3 | 要准 | FAQ、摘要、订单查询 |
| 0.7 | 要暖 | 客服对话、商品推荐 |
| 1.0 | 要新 | 营销文案、slogan |

> 核心心法：**稳定性与创意性不可兼得**——分类要稳用 0，对话要暖用 0.7，文案要新用 1.0。根据下游消费方式选温度，是 Prompt 工程的基本功。
