# 零样本 Prompt 模板合集

> 本文件提供 5 个零样本（Zero-Shot）Prompt 模板，场景全部围绕 SmartCS 电商客服：情感分类 / 意图识别 / 商品推荐 / FAQ 问答 / 工单摘要。每个模板含完整 Prompt、使用示例与预期输出。本文件与 `02-few-shot.md` 一一对应，可对比两者输出质量差异。

---

## 模板 1：情感分类零样本

### 模板说明
- 用途：判断用户消息的情感倾向
- 适用模型：通用
- 变量：`{{user_message}}`

### 完整模板
```
你是 SmartCS 客服的情感分析模块。请判断以下用户消息的情感倾向，只输出"正面/负面/中性"三个词之一，不要解释。

用户消息：{{user_message}}
```

### 使用示例
#### 输入
```
你是 SmartCS 客服的情感分析模块。请判断以下用户消息的情感倾向，只输出"正面/负面/中性"三个词之一，不要解释。

用户消息：耳机音质挺好的，就是续航有点短，整体还算满意。
```

#### 预期输出
```
正面
```

### 调优建议
- 温度建议：0（分类需确定性）
- 零样本下简单情感分类通常准确，但遇到反讽（"好得很，用一天就坏"）可能误判，需 Few-Shot 增强
- 若需置信度，可改为输出 JSON：`{"sentiment": "...", "confidence": 0.0-1.0}`

## 模板 2：意图识别零样本

### 模板说明
- 用途：识别用户消息的意图类别
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{user_message}}`

### 完整模板
```
你是 SmartCS 客服系统的意图识别模块。请对用户消息进行意图分类。

意图类别（仅限以下 5 类）：
- faq：常见问题咨询
- order_query：订单查询
- refund：退款/退货
- complaint：投诉

用户消息：{{user_message}}

输出要求：
- 以 JSON 输出：{"intent": "类别", "confidence": 0.0-1.0}
- 只能从上述类别中选择，不要编造新类别
- 不要输出 JSON 以外的任何内容
```

### 使用示例
#### 输入
```
你是 SmartCS 客服系统的意图识别模块。请对用户消息进行意图分类。

意图类别（仅限以下 5 类）：
- faq：常见问题咨询
- order_query：订单查询
- refund：退款/退货
- complaint：投诉

用户消息：我前天下的单子到哪了？

输出要求：
- 以 JSON 输出：{"intent": "类别", "confidence": 0.0-1.0}
- 只能从上述类别中选择，不要编造新类别
- 不要输出 JSON 以外的任何内容
```

#### 预期输出
```json
{"intent": "order_query", "confidence": 0.9}
```

### 调优建议
- 温度建议：0
- 零样本意图识别在常见表述下准确，但口语化或跨意图输入（"耳机坏了要退钱顺便投诉你们客服"）可能不稳定，建议加 Few-Shot
- 可增加 `unknown` 类别处理边界情况

## 模板 3：商品推荐零样本

### 模板说明
- 用途：根据用户需求推荐商品
- 适用模型：通用
- 变量：`{{user_need}}`、`{{candidates}}`

### 完整模板
```
你是 SmartCS 导购助手。请根据用户需求，从候选商品中推荐 1 款最合适的，并说明推荐理由（不超过 30 字）。

用户需求：{{user_need}}

候选商品：
{{candidates}}

输出格式：
商品名：xxx
理由：xxx
```

### 使用示例
#### 输入
```
你是 SmartCS 导购助手。请根据用户需求，从候选商品中推荐 1 款最合适的，并说明推荐理由（不超过 30 字）。

用户需求：预算 300 以内，想要降噪耳机，主要通勤用

候选商品：
- EarA 199元 无降噪 续航8h
- EarB 299元 有降噪 续航12h
- EarC 399元 有降噪 续航10h

输出格式：
商品名：xxx
理由：xxx
```

#### 预期输出
```
商品名：EarB
理由：有降噪契合通勤需求，299 元符合预算，续航 12h 表现优秀。
```

### 调优建议
- 温度建议：0.3
- 零样本推荐在需求明确时表现尚可，但格式控制较弱（可能输出多余解释），需明确输出格式
- 若需结构化数据，可改为 JSON 输出

## 模板 4：FAQ 问答零样本

### 模板说明
- 用途：根据 FAQ 知识库回答用户问题
- 适用模型：通用
- 变量：`{{faq_content}}`、`{{user_question}}`

### 完整模板
```
你是 SmartCS 客服。请仅根据下方 FAQ 知识库回答用户问题。

FAQ 知识库：
"""
{{faq_content}}
"""

用户问题：{{user_question}}

回答要求：
- 只能依据 FAQ 作答，不要编造
- 若 FAQ 无相关内容，回复"该问题暂未收录，已转人工"
- 回答不超过 100 字，语气专业礼貌
```

### 使用示例
#### 输入
```
你是 SmartCS 客服。请仅根据下方 FAQ 知识库回答用户问题。

FAQ 知识库：
"""
Q: 退货时效？ A: 7 天无理由，15 天质量问题。
Q: 运费谁付？ A: 质量问题卖家付，非质量问题买家付。
"""

用户问题：我收货 10 天了，耳机有杂音能退吗？运费谁出？

回答要求：
- 只能依据 FAQ 作答，不要编造
- 若 FAQ 无相关内容，回复"该问题暂未收录，已转人工"
- 回答不超过 100 字，语气专业礼貌
```

#### 预期输出
```
耳机杂音属于质量问题，15 天内可退货。质量问题退货运费由卖家承担。
```

### 调优建议
- 温度建议：0.2
- 零样本 FAQ 依赖模型理解能力，简单问答准确，复杂多跳问题可能遗漏
- FAQ 较长时建议用 RAG 检索 Top 3 再注入

## 模板 5：工单摘要零样本

### 模板说明
- 用途：将客服对话压缩为工单摘要
- 适用模型：GPT-4 / Claude / 通用
- 变量：`{{conversation}}`

### 完整模板
```
你是 SmartCS 工单生成模块。请将以下客服对话压缩为工单摘要，不超过 80 字，保留：订单号、用户诉求、当前进度。

对话记录：
"""
{{conversation}}
"""

输出格式：
- 订单：xxx
- 诉求：xxx
- 进度：xxx
```

### 使用示例
#### 输入
```
你是 SmartCS 工单生成模块。请将以下客服对话压缩为工单摘要，不超过 80 字，保留：订单号、用户诉求、当前进度。

对话记录：
"""
用户：耳机有杂音，订单 SO20240501，要退款。
客服：您好，请提供商品照片。
用户：[照片] 左耳杂音。
客服：已收到，提交退款工单，1-3 工作日到账。
"""

输出格式：
- 订单：xxx
- 诉求：xxx
- 进度：xxx
```

#### 预期输出
```
- 订单：SO20240501
- 诉求：耳机左耳杂音，申请退款
- 进度：已提交退款工单，预计 1-3 工作日到账
```

### 调优建议
- 温度建议：0.2
- 零样本摘要在对话较短时表现良好，长对话可能遗漏关键信息
- 若需固定字段结构，可改为 JSON 输出并指定 schema

## 零样本模板总结

| 模板 | 场景 | 零样本表现 | 局限 |
|------|------|-----------|------|
| 情感分类 | 简单正负 | 较好 | 反讽易误判 |
| 意图识别 | 5 类分类 | 一般 | 口语/跨意图不稳 |
| 商品推荐 | 需求匹配 | 一般 | 格式控制弱 |
| FAQ 问答 | 知识库问答 | 较好 | 多跳问题易遗漏 |
| 工单摘要 | 对话压缩 | 较好 | 长对话易丢信息 |

> 零样本适合快速验证与简单任务。当输出格式不稳或准确率不足时，请升级为 `02-few-shot.md` 中的少样本版本。
