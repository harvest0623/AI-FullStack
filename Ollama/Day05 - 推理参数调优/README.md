## 一、模型输出是怎么来的

模型每个 token 都输出一个**概率分布**（下一个词是谁的概率）：

```
输入"今天天气很" -> 模型概率：{好:0.5, 差:0.2, 不错:0.15, 棒:0.1, ...}
```

**采样（sample）** 就是从这个分布里挑一个 token 的过程。参数控制"怎么挑"：

- 完全取概率最高 → 确定性（贪婪 greedy）
- 偏向高概率但不排除低概率 → 多样性（随机采样）

---

## 二、采样参数家族

### 2.1 temperature（温度）— 最常用

控制概率分布的"尖锐度"：

```
低温(0.1)：概率差放大，几乎总选最高——稳定、保守、复现率高
高温(1.0+)：拉平概率，常选非最高——多样、有创意、可能胡说
```

| 温度 | 行为 | 适用 |
|------|------|------|
| 0~0.3 | 几乎确定 | 事实问答、代码、抽取 |
| 0.5~0.7 | 均衡 | 一般对话 |
| 0.8~1.2 | 多样 | 头脑风暴、创意写作 |

### 2.2 top_p（核采样）

只保留"累积概率达 p 的 token 池"，再从池中采样。p 越小越保守。

```
top_p=0.9：去掉尾部长尾，保留概率最高的 90%
top_p=0.1：只留非常靠前的 token，非常保守
```

### 2.3 top_k（top-k 采样）

只从概率最高的 k 个 token 中选。

- top_k=1：等价 greedy（最确定）
- top_k=40：年轻模型常用默认

> temperature / top_p / top_k 三个一起控制"随机性/多样性"，可配合用。

## 三、长度与约束参数

| 参数 | 作用 | 典型值 |
|------|------|--------|
| `num_predict` | 最多生成多少个 token（即 max_tokens） | 128-4096 |
| `stop` | 命中即停止的序列列表 | ["\n\n", "END"] |
| `seed` | 随机种子，相同 seed 复现相同输出 | 42 |

### 3.1 seed 复现

```
同 prompt + 同参数 + 同 seed -> 同输出（用于测试/对拍）
不同 seed -> 即便其他相同，输出也可能不同
```

---

## 四、repeat_penalty（重复惩罚）

防止模型陷入重复循环：

```
repeat_penalty=1.0：不惩罚（可能不断重复）
repeat_penalty=1.1~1.3：常用，抑制重复
过高：可能破坏连贯/新奇也被压
```

当模型出现"无限复读"时，调高 repeat_penalty 是最直接解法。

## 五、参数组合速查

| 场景 | temperature | top_p | num_predict | 备注 |
|------|-------------|-------|-------------|------|
| 事实/抽取 | 0.1~0.3 | 0.1~0.5 | 视需要 | 求稳 |
| 一般对话 | 0.6~0.8 | 0.9 | 默认 | 均衡 |
| 代码 | 0.2~0.4 | 0.3~0.9 | 大 | 求准 |
| 创意写作 | 0.9~1.2 | 0.95 | 大 | 求活 |
| 测试复现 | 任意+seed=固定 | ... | ... | 同 seed 同输出 |

---

## 六、今日核心要点

```
1. 采样 = 从概率分布挑 token，参数控"怎么挑"
2. temperature：拉尖/拉平概率（稳→活）
3. top_p/top_k：限制候选池（保守程度）
4. num_predict：输出长度上限
5. seed：定种子 -> 可复现
6. stop：命中即止
7. repeat_penalty：抑制复读
8. 组合：事实求稳、写作求活、测试用固定 seed
```
