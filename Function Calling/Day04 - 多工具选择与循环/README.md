# Day04 - 多工具选择与循环

> 本节目标：模型面对**多个可用工具**时，能依据描述和用户意图**选对工具**，
> 并支持在一次整体对话里连续（按轮）调用不同函数，形成多步流水线。

---

## 1. 多工具 = 一个"工具箱"

注册多个工具后，模型每次决策要在它们之间做**选择**：

```python
registry.add(weather_spec)
registry.add(add_spec)
registry.add(search_book_spec)
registry.add(convert_c2f_spec)
```

模型看到的 `tools` 是一个列表，它根据用户问题 + 每个工具的 `description` 决定调哪个。

---

## 2. 模型怎么"选对"

靠**描述(description)差异化**：哪个功能匹配当前用户意图就选哪个。

| 用户意图 | 该选 | 触发信号 |
|----------|------|----------|
| 查天气 | `get_weather` | 提到城市+天气 |
| 算数 | `add` | 两个数字、"和"、"+" |
| 找书 | `search_book` | 书/收藏/检索 |
| 温度转换 | `convert_c2f` | 摄氏/华氏/度 |

规则 planner 里就是"关键词分流"，而真实模型靠语义理解 + 描述做到同样的事。

---

## 3. 两种"多工具"理解

- **多工具选择**：不同请求挑不同工具（本 Day 侧重）。
- **并行调用**：*同一次*决策里发多个工具调用（Day08 侧重）。

框架的 `chat_with_tools` 天然支持连续多轮，每轮模型都可能trigger一个新工具。

## 5. 你要记住的三句话

1. 多个工具 = 一次决策一次**选择**，description 越清晰越选得对。
2. 一次对话可**连续多轮**不同工具调用，形成流水线。
3. 工具职责彼此**互不重叠**最好，减少模型混淆。
