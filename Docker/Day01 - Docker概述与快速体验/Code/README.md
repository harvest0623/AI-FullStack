# Code 说明

本目录为「Day01 - Docker概述与快速体验」的可执行代码。

- 01_what_is_docker.py    镜像/容器/仓库 + 架构
- 02_vm_vs_container.py   容器 vs 虚拟机
- 03_hello_world.py       hello-world 全流程
- docker_check.py         Docker 环境检测（各天共用）
- README.md

运行方式：

```bash
python 01_what_is_docker.py
python 02_vm_vs_container.py
python 03_hello_world.py
python docker_check.py
```

> 全部离线可运行。安装 Docker 并启动后，`03` 与 `docker_check` 会检测到真实环境并提示真实命令。
