# Day07 - 数据卷与持久化

> 容器的可写层会随容器删除而消失，所以**数据库、上传文件、模型缓存**等需要持久化的数据必须放在容器外的**数据卷**里。今天讲清命名卷与绑定挂载，以及备份恢复。

## 核心概念

- **可写层易失**：容器删除 → 可写层数据丢失。
- **命名卷**：由 Docker 管理，持久、可移植，适合应用/库数据。
- **绑定挂载**：把宿主机目录直接挂进容器，适合开发热更新。
- **只读挂载**：`-v ...:...:ro` 给容器只读访问。
- **备份恢复**：用一次性容器把卷打 tar、再解包。

## 知识点速查

| 项 | 说明 |
|----|------|
| 命名卷 | `-v name:/data`，Docker 管理、持久 |
| 绑定挂载 | `-v /宿主路径:/data`，宿主目录直挂 |
| 只读 | 追加 `:ro` |
| 备份 | 临时容器 `tar czf` |
| 恢复 | 临时容器 `tar xzf` |
| 卷命令 | `docker volume ls / create / inspect` |
| 适用 | 库数据/模型→命名卷；开发源码→绑定 |
