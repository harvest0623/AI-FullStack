# Code 说明

本目录为「Day05 - 网络与端口」的可执行代码。

- 01_network_model.py  网络模式对比
- 02_port_map.py       端口映射原理
- 03_container_net.py  自定义网络与容器互联
- docker_check.py      Docker 环境检测（各天共用）
- README.md

运行方式：

```bash
python 01_network_model.py
python 02_port_map.py
python 03_container_net.py
```

> 全部离线可运行。有 Docker 时脚本会提示真实命令供对照。
