## 核心概念

- **网络模式**：bridge（默认）/ host / none / 自定义 bridge。
- **端口映射**：`-p 宿主端口:容器端口`，做客机访问容器服务的桥。
- **容器互联**：自定义网络中按容器名解析，比 IP 可靠。
- **bridge 网桥**：默认 `docker0`，容器间可互通。

---

## 今日学习目标

- 说出四种网络模式及适用场景
- 理解并用好端口映射 `-p`
- 创建自定义网络并实现容器按名字互联
- 知道为何多容器应用用"自定义网络 + 名字"而非 IP

## 知识点速查

| 项 | 说明 |
|----|------|
| bridge（默认） | 内网段，端口映射对外 |
| host | 共享宿主网络栈 |
| none | 无网络 |
| 自定义 bridge | 容器按名字互联 |
| `-p 宿主:容器` | 端口映射 |
| `-P` | 随机映射 EXPOSE 端口 |
| 互联 | 容器名.DNS（自定义网络内） |
