## 核心概念

- **镜像分层**：镜像由多个只读层叠加；层来自 Dockerfile 的每条指令。
- **可写层**：容器启动时在镜像之上加一层可写层（Copy-on-Write）。
- **写时复制**：读在底层、写在顶层，删除不动底层。
- **层缓存**：指令未变的层直接复用，构建快。
- **层共享**：多个镜像共享公共底层，省空间。
- **tag**：`仓库:标签`，用于版本化镜像。

## 知识点速查

| 项 | 说明 |
|----|------|
| 只读层 | 镜像由只读层叠加，来自指令 |
| 可写层 | 容器专有，写时复制 |
| 写时复制 | 读底层、写顶层，删不动底层 |
| 层缓存 | 未变层复用，构建快 |
| 层共享 | 公共底层多镜像共用 |
| tag | repo:tag，版本化 |
