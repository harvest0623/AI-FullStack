> 给 Agent 装上"海马体"：掌握记忆分层（工作/短时/长时）、对话历史裁剪与摘要、长时记忆的写入与检索、记忆打分与淘汰，让 Agent 跨步骤、跨会话保持连贯。

## 二、为什么 Agent 需要记忆

Agent 循环的每一步都在消耗**上下文窗口**，但现实任务要求：

| 问题 | 没有记忆的后果 |
|------|--------------|
| 多步任务中前面的观察被挤掉 | 重复查询、自相矛盾 |
| 上下文塞满全部历史 | 贵、慢、超窗口 |
| 换个会话就不认识用户 | 每次从零开始 |
| 记不住"上次怎么解决的" | 同样的错反复犯 |

**核心矛盾**：窗口有限（短时）vs 经验无限（长时）——记忆系统就是解决这个矛盾的工程。

## 三、记忆三层结构

```
┌─────────────────────────────────────────────┐
│ 工作记忆 Working Memory                       │
│ 当前这一步正在用的信息（scratchpad）            │
│ 生命周期：单步                                    │
├─────────────────────────────────────────────┤
│ 短时记忆 Short-term（对话上下文）                │
│ 当前任务的 Thought/Action/Observation 序列      │
│ 生命周期：单任务；受窗口约束，需裁剪/摘要          │
├─────────────────────────────────────────────┤
│ 长时记忆 Long-term（外部存储）                   │
│ 跨会话的事实/偏好/经验，按需检索                  │
│ 生命周期：永久；容量大，靠检索而非全量加载          │
└─────────────────────────────────────────────┘
```

| 层 | 类比 | 实现 |
|----|------|------|
| 工作记忆 | 草稿纸 | 变量 / scratchpad |
| 短时记忆 | 正在聊的话题 | messages 数组 + 裁剪 |
| 长时记忆 | 笔记本/经验 | 向量库/键值库 + 检索（接 VectorDB 板块） |

## 四、短时记忆管理：裁剪与摘要

上下文 = 系统提示 + 历史消息 + 工具结果。三种策略：

### 4.1 滑动窗口（截断）

```
保留最近 N 条消息，旧消息直接丢弃
优点：简单、快
缺点：早期关键信息丢失（如用户一开始说的目标）
```

### 4.2 摘要压缩

```
窗口快满时，把旧消息压缩成一段摘要，再拼上最近消息
优点：保留长程要点
缺点：摘要有损，可能丢细节；多一次 LLM 调用
```

### 4.3 混合策略（生产常用）

```
System（永不裁） + 任务目标（永不裁） + 旧消息摘要 + 最近 K 条原文 + 当前观察
```

> **工程细节**：工具返回的大 JSON 先截断再入历史；结构化的 Observation 可以只存"结论"不存"原始数据"。

## 五、长时记忆：写入与检索

### 5.1 记什么

| 类型 | 例子 | 写入时机 |
|------|------|---------|
| 用户事实 | 偏好、称呼、时区 | 对话中显式出现 |
| 任务经验 | 某工具参数怎么写才对 | 任务完成后反思 |
| 环境事实 | 数据表结构、API 用法 | 首次发现时 |

### 5.2 怎么检索

- **关键词**：简单场景，字符串匹配
- **向量检索**：语义相近召回（RAG 同款技术，复用 VectorDB 能力）
- **元数据过滤**：按 user_id / 时间 / 类型先筛再排

### 5.3 检索后怎么用

检索到的记忆以**系统消息或上下文前缀**注入："你记得：用户偏好中文回复；上周任务用 calc 工具算过环比……"

## 六、记忆打分与淘汰

长时记忆不能只进不出，否则检索噪声越来越大：

| 因子 | 说明 |
|------|------|
| 重要性 importance | 事实类 > 闲聊类 |
| 使用频率 recency+frequency | 常被召回的保留 |
| 时效性 decay | 过期事实降权/清除 |
| 容量上限 | 超限时淘汰总分最低者 |

**常见淘汰公式**：`score = importance × (频率权重) × e^(-λ·天数)`，保留 Top-N。

## 十、小结

- **三层记忆**：工作（单步草稿）/ 短时（任务内上下文）/ 长时（跨会话存储）
- **短时管理**：窗口截断省事、摘要保留要点、混合策略生产常用
- **长时记忆**：写什么（事实/经验）+ 怎么取（关键词/向量/过滤）
- **打分淘汰**：重要性 × 频率 × 时效，防止记忆腐化

**今日金句**：窗口是易忘的现在，记忆是可检索的过去；裁剪让 Agent 走得快，长时记忆让它走得远。
