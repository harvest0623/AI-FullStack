# Day05 - 代码运行说明

本文件夹实现**任务规划与分解**：Plan-and-Execute、DAG 依赖图、动态重规划与 TODO 清单驱动。

## 运行环境

- 纯 Python 标准库，无第三方依赖

## 文件说明与运行

| 文件 | 说明 | 运行 |
|------|------|------|
| `01_plan_execute.py` | Plan-and-Execute：先规划清单再逐步执行 | `python 01_plan_execute.py` |
| `02_task_dag.py` | DAG：依赖声明 + 拓扑分层 + 并行波次调度 | `python 02_task_dag.py` |
| `03_replan.py` | 失败触发的动态重规划（保留成果+重排未来） | `python 03_replan.py` |
| `04_todo_driver.py` | TODO 清单状态机 + 动态追加/取消 | `python 04_todo_driver.py` |

## 典型输出速览

```
# 02_task_dag.py
  Wave 1（并行执行）: ['查本月', '查上月', '查行业']
  Wave 2（顺序执行）: ['算环比', '算差距']
  Wave 3（顺序执行）: ['汇总']

# 03_replan.py
  ❌ 失败: {'error': 'timeout'} -> 触发第 1 次重规划
  新计划：
    ✓ 1. 查本月销量
      2. 查行业均值(备用源)
      3. 算领先幅度
      4. 汇总结论

# 04_todo_driver.py
  [x] 1. 查询本月销量  # 1450
  [x] 2. 查询上月销量  # 980
  [x] 3. 计算环比  # -32.4%
  [-] 4. 环比出现下滑，补充：查询品类结构  # 权限不足，报告中注明
  [x] 5. 撰写报告结论  # ...
```

## 核心结论

1. **规划换全局**：先出计划再执行，长任务不迷路；执行器每步只需当前上下文，省 token。
2. **DAG 显式依赖**：无依赖节点自动归入同一波次，天然可并行。
3. **Replan 三原则**：保留已完成成果、依据失败观察选新方案、限制重规划次数。
4. **清单即状态机**：`[ ]→[~]→[x]/[-]`，可动态追加子任务，取消保留痕迹。
