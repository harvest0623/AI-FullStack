## 二、Agent 评估为什么难

单轮 LLM 评估看"答案对不对"；Agent 评估面对的是：

1. **多步**：10 步里错 1 步，结果可能对也可能错
2. **非确定**：同一个任务跑两次，路径可能不同
3. **过程即质量**：绕远路拿到正确答案也算劣化
4. **环境依赖**：工具结果会变（数据更新），评估要可复现

> **核心思想**：Agent 评估 = **结果评估（End-to-End）+ 轨迹评估（Step-wise）**，缺一不可。

## 三、评估指标体系

### 3.1 结果指标（任务达成）

| 指标 | 定义 | 采集 |
|------|------|------|
| **任务成功率** | 最终答案/状态正确的比例 | 人工标注或断言校验 |
| **部分完成率** | 子目标完成的平均比例 | TODO 完成度 |
| **正确性** | 答案与标注一致（数值/包含关键事实） | 精确匹配或语义判分 |

### 3.2 过程指标（效率与稳健）

| 指标 | 定义 | 健康信号 |
|------|------|---------|
| **步数** | 完成任务用的循环步数 | 越少越好（对比同类任务） |
| **工具命中率** | 有效调用 / 总调用 | 高=不瞎调 |
| **重试率** | 失败重试的占比 | 低=一次做对 |
| **死循环率** | 触发重复检测/超步数的比例 | 越低越好 |

### 3.3 成本指标

| 指标 | 定义 |
|------|------|
| **token 消耗** | 每任务平均 token（输入+输出） |
| **工具成本** | 高价工具的调用次数 × 单价 |
| **延迟** | 任务总耗时 / P95 |

### 3.4 安全指标（预览，Day09 详讲）

越权调用率、护栏拦截率、敏感输出泄漏率。

## 四、轨迹调试：找到走歪的那一步

拿到失败案例后，调试三板斧：

```
1. 看轨迹全貌     goal + 每步 (Thought/Action/Observation)
2. 二分定位       从"结果错误"回溯第一个"可疑观察"
3. 单步重放       只重跑可疑步骤，隔离验证
```

**可疑信号**：
- Thought 说 A，Action 却调 B（决策与文字不一致）
- Observation 明明报错，下一步却当成功继续（忽视错误）
- 重复调用同一工具同参数（打转）
- 最终答案引用了从未出现过的数字（结果幻觉）

## 五、五大典型失败模式

| 模式 | 症状 | 根因 | 对策 |
|------|------|------|------|
| **死循环** | 反复同一步 | 缺终止条件/模型短视 | 重复检测+max_steps+Prompt 提醒 |
| **幻觉工具** | 调不存在的工具 | 记忆里"以为有" | 白名单+可用清单回填 |
| **参数幻觉** | 编造参数值 | 缺校验/描述含糊 | Schema 强校验+可指导报错 |
| **过早放弃** | 浅尝辄止就直答 | Prompt 无坚持引导 | 任务完成判据+鼓励重试 |
| **观察误读** | 明明失败当成功 | 上下文太长淹没了错误 | 错误显式标记+短上下文 |

## 六、A/B 对比实验

改了 Prompt/工具描述/模型后，怎么证明"变好了"？

```
1. 固定数据集：N 个任务 + 期望结果（评估集不可变）
2. 跑 A 版本：记录成功率/步数/token/失败模式分布
3. 跑 B 版本：同数据集同配置（除改动项）
4. 对比：不只看总体成功率，还要看失败模式迁移
     （A 的死循环修好了，B 是否引入新的观察误读？）
5. 多次运行取均值：非确定性下，单次对比不可信
```

> **回归思维**：每次改动跑评估集 = Agent 的"单元测试"。没有评估集的改动都是盲改。

## 七、评估数据集建设

| 要素 | 说明 |
|------|------|
| 任务样本 | 覆盖：简单/复杂/边界/已知失败场景 |
| 期望结果 | 精确答案 or 判分标准（rubric） |
| 环境快照 | 工具返回的固定 stub（保证可复现） |
| 标注轨迹 | 可选：专家示范路径（评估路径效率） |

**积累方式**：线上失败案例 → 脱敏入库 → 成为回归测试用例。**失败案例是最宝贵的数据集来源。**

## 十一、小结

- **评估三层**：结果（成功率）、过程（步数/命中/重试）、成本（token/延迟/金额）
- **调试靠轨迹**：全貌回放 + 二分定位 + 单步重放
- **五大失败模式**：死循环/幻觉工具/参数幻觉/过早放弃/观察误读——对症下药
- **A/B + 回归**：评估集是 Agent 的单元测试，改动必跑

**今日金句**：没有评估的 Agent 优化是玄学，没有轨迹的调试是算命。
