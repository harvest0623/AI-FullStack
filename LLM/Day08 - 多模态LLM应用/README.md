# Day08 - 多模态 LLM 应用

多模态 LLM 打破了文本的边界，让 AI 能看、能听、能说，开启了更广阔的应用场景。GPT-4o 接收一张发票照片就能吐出结构化字段，Whisper 听一段中文语音就能转成文字，TTS 把一段文案合成自然语音，Gemini 1.5 Pro 甚至能"看"完一整段视频再回答问题。从"图文问答"到"文档解析"、从"表单识别"到"UI 转代码"，多模态能力正在把 LLM 从"聊天框"推进到"全感官助手"。本章系统讲解 GPT-4o / Claude 3.5 / Gemini 的多模态能力、图像与音频输入方式、Whisper 语音识别与 TTS 语音合成、视频理解，以及多模态应用场景与成本管理，让 `AISearch` 项目从"只能打字"升级为"能看能听能说"。

## 理论知识讲解

### 8.1 多模态 LLM 概念

#### 8.1.1 什么是多模态

**多模态**（Multimodal）指模型能统一处理文本 + 图像 + 音频 + 视频等多种输入输出形式。传统 LLM 只懂文本，多模态 LLM 把视觉编码器、音频编码器等接入语言模型，实现跨模态理解与生成。

#### 8.1.2 发展历程

| 阶段 | 代表模型 | 能力 |
|------|---------|------|
| 2021 | CLIP（OpenAI） | 图文匹配，学习图文对齐表示 |
| 2023 | GPT-4V | 图像理解，描述 / OCR / 分析 |
| 2024 | GPT-4o | 全模态，文本 + 图像 + 音频输入输出 |
| 2024 | Gemini 1.5 Pro | 全模态 + 超长上下文，支持视频 |
| 2024 | Claude 3.5 Sonnet | 图像理解 + 文档解析 |

#### 8.1.3 架构思路

```text
图像 → 视觉编码器(ViT) ─┐
                        ├→ 跨模态融合 → 语言模型 → 文本输出
文本 → 文本编码器 ──────┘
```

视觉编码器把图像切成 patch，编码为向量序列；文本编码器把文本编码为向量；两者在跨模态融合层对齐，再送入语言模型生成回答。

### 8.2 GPT-4o / GPT-4 Vision 能力

| 能力 | 说明 | 示例 |
|------|------|------|
| 图像描述 | 描述图像内容 | "这张图里有什么？" |
| OCR 文字识别 | 提取图中文字 | 发票 / 截图 / 标牌 |
| 图表分析 | 解读柱状图 / 折线图 | "2024 年 Q3 销售额是多少？" |
| 表格提取 | 把图中表格转为结构化数据 | 财报表格 → JSON |
| 图像对比 | 多图差异分析 | "两张图哪里不同？" |
| 图文对话 | 基于图像回答问题 | 客服产品图问答 |
| UI 转代码 | 从截图生成前端代码 | 设计稿 → HTML/CSS |
| 数学推理 | 从手写公式图解题 | 拍照解题 |

### 8.3 Claude 3.5 Vision

- 图像理解能力整体接近 GPT-4V，部分场景（文档解析）更优。
- 支持多图输入（一条消息含多张图片）。
- 200K 长上下文，适合长文档 + 多图组合分析。
- 文档解析强项：PDF / 图表 / 扫描件结构化。

### 8.4 Gemini 多模态能力

- **视频理解**：上传视频 → 提问分析（"视频第 30 秒发生了什么？"）。
- **音频理解**：语音内容分析（无需 Whisper 中转）。
- **全模态融合**：文本 + 图像 + 音频 + 视频统一处理。
- 1M+ 超长上下文，可处理长视频 / 多图。

### 8.5 图像输入方式

#### 8.5.1 URL 引用

```python
messages = [{
    "role": "user",
    "content": [
        {"type": "text", "text": "描述这张图"},
        {"type": "image_url", "image_url": {"url": "https://example.com/img.png"}},
    ],
}]
```

**适用**：图像已在线上（CDN / OSS）；不想编码大文件。

#### 8.5.2 Base64 编码

```python
import base64
b64 = base64.b64encode(open("img.png", "rb").read()).decode()
messages = [{
    "role": "user",
    "content": [
        {"type": "text", "text": "描述这张图"},
        {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{b64}"}},
    ],
}]
```

**适用**：本地图片；隐私敏感不便上传 URL。

#### 8.5.3 文件上传

通过 Files API 上传后引用，适合大文件或复用。

#### 各方式对比

| 方式 | 优点 | 缺点 | 适用 |
|------|------|------|------|
| URL | 简单、不增加请求体积 | 需图像可公网访问 | 线上图片 |
| Base64 | 本地可用、隐私好 | 体积膨胀 33%，请求大 | 本地 / 隐私 |
| 文件上传 | 可复用、支持大文件 | 多一步上传 | 大文件 / 复用 |

### 8.6 多图像对话

在一条消息的 `content` 里放多个 `image_url` 块即可：

```python
content = [
    {"type": "text", "text": "对比这两张图，找出差异"},
    {"type": "image_url", "image_url": {"url": url1}},
    {"type": "image_url", "image_url": {"url": url2}},
]
```

应用：图像对比 / 排序 / 关联分析 / 多角度产品审查。

### 8.7 音频处理

#### 8.7.1 Whisper 语音识别 STT

OpenAI `audio transcriptions` API：

```python
with open("audio.mp3", "rb") as f:
    transcript = client.audio.transcriptions.create(model="whisper-1", file=f)
print(transcript.text)
```

- 模型：`whisper-1`
- 支持多语言（自动检测）+ 翻译（多语言 → 英文）
- 长音频：支持（按文件大小分片）

#### 8.7.2 TTS 语音合成

OpenAI `audio speech` API：

```python
response = client.audio.speech.create(
    model="tts-1",
    voice="alloy",
    input="你好，欢迎使用 AISearch。",
)
response.write_to_file("output.mp3")
```

- 模型：`tts-1`（标准）/ `tts-1-hd`（高清）
- 声音：`alloy` / `echo` / `fable` / `onyx` / `nova` / `shimmer`
- 多语言：支持中英等

#### 8.7.3 语音翻译

`audio translations` API：把任意语言语音翻译成英文文字（注意：输出固定为英文）。

### 8.8 视频理解

#### 8.8.1 Gemini 视频分析

上传视频文件 → 提问：

video_file = genai.upload_file("video.mp4")

### 8.10 多模态 Prompt 技巧

1. **明确关注点**：指出关注图像哪个部分（"请只关注左上角的表格"）。
2. **引导结构化输出**：要求 JSON / Markdown 表格，便于程序消费。
3. **多图对比时明确维度**：说清对比什么（"从颜色、布局、文字三方面对比"）。
4. **OCR 任务给上下文**：告知文档类型（"这是一张增值税发票"）。
5. **限制输出长度**：避免冗长描述。

### 8.11 多模态成本管理

#### 8.11.1 图像 Token 消耗

OpenAI 按"分辨率 tile"计算图像 Token：

| 图像尺寸 | 大致 Token |
|---------|-----------|
| 512×512 | ~170 |
| 1024×1024 | ~340（含细节 tile） |
| 2048×2048 | ~580+ |

**控制策略**：上传前压缩到合适分辨率（如 1024×1024）；避免传原图。

#### 8.11.2 音频计费

- Whisper：按音频时长计费（$0.006/分钟）。
- TTS：按输入字符数计费。

#### 8.11.3 成本控制策略

1. 图像压缩到必要分辨率。
2. 优先用 URL 而非 Base64（减少请求体积）。
3. 缓存重复图像的识别结果。
4. 批量处理用 Batch API（50% 折扣）。

### 练习 1：发票字段提取

准备一张发票照片（或用网图），用 `02_image_analysis.py` 的 `ImageAnalyzer.extract_table` 提取发票号、日期、金额、卖方等字段，输出 JSON。验证字段完整性。

### 练习 2：UI 截图转代码

**提示**：要求"使用语义化 HTML + Tailwind CSS"，效果更好。

### 练习 3：语音问答闭环

录一段中文提问音频，用 `03_whisper_stt.py` 转成文字 → 调 LLM 回答 → 用 `04_tts_demo.py` 把回答合成语音。完整跑通"语音输入 → 文字回答 → 语音输出"链路。

**提示**：中间的文字回答可调 Day02 的统一客户端；TTS 选 `nova` 或 `shimmer` 中文效果较好。
